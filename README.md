# 🦸 Marvel Multiverse Watchlist

A sleek, self-contained single-page watchlist tracker for the entire Marvel universe — MCU, X-Men, Spider-Verse, Fantastic Four, and Legacy Classics.

## ✨ Features

- 🎬 **130+ Marvel titles** across Movies, Series, and Shorts
- 🗂️ **5 Franchise tabs** — MCU · X-Men · Spider-Verse/SSU · Fantastic Four · Legacy Classics
- 📊 **Live progress dashboard** with animated progress bar and per-category stats
- 🔍 **Real-time search** by title or franchise
- 🔽 **Status filters** — All / Watched / Unwatched
- ✅ **Batch actions** — Select All / Unselect All (context-aware)
- 💾 **Persistent state** via `localStorage` — your progress is saved automatically
- 📤 **Export / Import** JSON backup of your watchlist
- 🔄 **Reset** with confirmation dialog
- 🔔 **Toast notifications** for actions
- 📱 **Fully responsive** — works on desktop and mobile

## 🚀 Getting Started

No installation or build step required. Just open the file in any modern browser:

```bash
# Clone the repo
git clone https://github.com/antonystarc/MCU.git

# Open in browser
open MCU.html        # macOS
start MCU.html       # Windows
xdg-open MCU.html   # Linux
```

Or simply **[download MCU.html](./MCU.html)** and open it directly.
